# 墨尔本国庆之旅 · 路线规划 Demo

四人同行（2026/9/30 - 10/7）的旅行路线规划工具原型：以已确定的行程蓝本为骨架，组员可在地图上添加打卡点（餐厅 / 景点 / 咖啡等），当天路线**按真实道路自动重算经过新点**，地点简介以卡片形式陈列在路线旁边。

## 怎么运行

无需安装任何东西，二选一：

- **直接双击 `index.html`** 在浏览器打开（推荐 Chrome / Edge）；
- 或在本目录起一个本地服务：`python -m http.server 8000`，浏览器访问 `http://localhost:8000`。

> 首次打开需要联网加载地图瓦片与路线服务。若底图/路线加载慢，属境外服务网络波动，刷新重试即可；路线服务不可用时会自动降级为虚线直线 + 估算车程，功能不中断。

## 功能清单

| 功能 | 说明 |
|---|---|
| 行程总览 | 首个 Tab 一屏看全部 8 天路线（每天一种颜色），点击某天进入细节 |
| 按天查看 | 顶部日期 Tab 切换；地图显示当天路线，序号即途经顺序 |
| 真实道路路线 | OSRM 开源导航引擎按驾车道路计算，非两点直线 |
| 段间距离/车程 | 侧栏每两张卡片之间显示该段实际距离与时长，顶部有当天总里程/总车程 |
| 添加打卡点 | 点「➕ 点击地图添加打卡点」→ 点击地图位置 → 填名称/类型/简介；或用搜索框按名称查地点（覆盖澳大利亚） |
| 路线自动重算 | 增删、上下移动、拖动任意 Pin 后，当天路线与所有距离立即重算 |
| 简介卡片 | 侧栏卡片（点击展开全文）+ 地图 Pin 弹窗双呈现 |
| 数据持久化 | 自动存浏览器 localStorage，关掉再开不丢 |
| 导出/导入 JSON | 「导出」生成文件发微信群，组员「导入」即同步；「恢复蓝本」一键回到初始行程 |

## 技术选型（为什么不是谷歌/高德/Mapbox）

- **谷歌地图**：境外数据体验天花板，但境内无法访问，开发与使用都不现实，排除。
- **高德/百度**：合规最稳、国内最快，但**驾车路径规划仅支持中国境内**——"加 Pin 自动改路线"这个核心功能在墨尔本无法实现，只能画直线，排除。
- **Mapbox**：体验最接近谷歌的商用方案，全球路线规划可用，但需要注册账号换取 token 才能跑通。Demo 阶段选择了零门槛替代 ↓
- **本 Demo 采用**：Leaflet（开源地图引擎）+ CARTO Voyager 瓦片（风格清新接近谷歌）+ OSRM 公共路线服务 + Nominatim 地点搜索（OpenStreetMap 生态，澳洲数据质量很高）。全部免费、无需注册、无需 API key。

### 合规说明

所有行程点位均在**境外（澳大利亚）**，使用国际标准 WGS-84 坐标系，不涉及中国境内地理信息的采集与展示；软件仅旅行小组内部使用、不对外公开运营，不属于"向公众提供互联网地图服务"的监管范畴。若将来要公开上线并加入境内地点，需切换到有测绘资质的厂商（高德/百度/腾讯），见下节预留的切换点。

### 将来切换到 Mapbox（体验最接近谷歌）

1. 注册 mapbox.com 账号，获取免费 token；
2. 引入 `mapbox-gl.js` 替换 Leaflet（或继续用 Leaflet + Mapbox 瓦片：把底图 URL 换成 `https://api.mapbox.com/styles/v1/mapbox/streets-v12/tiles/{z}/{x}/{y}?access_token=YOUR_TOKEN`）；
3. 把 `routeFor()` 里的 OSRM 请求换成 Mapbox Directions API：`https://api.mapbox.com/directions/v5/mapbox/driving/{lon,lat;lon,lat}?access_token=YOUR_TOKEN`，返回结构同样是 `geometry + 每段 distance/duration`，改动量很小。

路线计算已经集中在 `routeFor()` 单个函数里，就是为了留这个切换点。

## 数据结构

导出的 JSON 即完整数据模型：

```jsonc
{
  "trip": "墨尔本国庆之旅",
  "days": [
    {
      "id": "d3", "date": "10/2 周五", "title": "莫宁顿半岛一日游",
      "color": "#f59e0b",       // 当天路线颜色
      "note": "当天提示…",
      "places": [                // 数组顺序 = 途经顺序
        { "id": "…", "name": "…", "type": "food",
          "coords": [-38.2216, 145.0389],   // WGS-84 [纬度, 经度]
          "desc": "简介卡片内容", "blueprint": true }   // blueprint=false 为组员新增
      ]
    }
  ]
}
```

## 已知局限 / 下一步路线图

- 路线为**驾车**模式；10/1 市区步行日的距离仅作参考（提示已写在当天 note 里）。
- OSRM / Nominatim 为公共服务，有速率限制，demo 与小团队使用足够，不适合公开运营。
- 蓝本坐标为预录入的近似值，个别点可能有百米级偏差——地图上拖动 Pin 即可修正，会自动保存。
- 二期方向：① 云端实时协作（Supabase 免费层，国内可访问，组员各自添加互相可见）；② 换 Mapbox 底图与路线；③ 每站预计停留时间与时刻表推算；④ 组员投票/评论 Pin。
